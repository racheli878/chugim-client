# חוגים — צד לקוח

React 18 + Vite, ‏JavaScript ו-CSS ידני, בעברית מימין לשמאל. הלקוח עובד מול ה-API של פרויקט Chugim.

## הרצה

```bash
npm install
npm run dev     # http://localhost:5173
```

השרת צריך לרוץ במקביל (ברירת מחדל `https://localhost:7180`). הכתובת מוגדרת ב-`.env.development` במשתנה `VITE_API_URL`.
